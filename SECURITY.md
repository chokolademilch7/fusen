# Security

## Reporting a vulnerability

If you find a vulnerability, **do not write it in a public issue or pull request**. Report it
privately through this repository's **Security tab → "Report a vulnerability"** (GitHub private
vulnerability reporting). Only the maintainers can see the report.
If that button is missing, open an issue that only asks for a private contact, with no details
of the vulnerability.

Please include:

- The affected package (`@chokolademilch7/fusen/server`, `@chokolademilch7/fusen/ui`, `@chokolademilch7/fusen/lite`, `@chokolademilch7/fusen/mcp`, ...) and commit
- Steps to reproduce (a minimal HTML page or request makes it faster)
- What an attacker can do (delete other people's comments, for example)

Only the latest `main` branch is supported. There are no releases or versions yet.
